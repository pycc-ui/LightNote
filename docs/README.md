## 怎么加一个新功能

改动直接写进对应的设计文档：界面改动写进[界面设计](界面设计.md)，表改动写进[数据库设计](数据库设计.md)，AI 行为改动写进[AI接入设计](AI接入设计.md)、命令改动写进[命令语言设计](命令语言设计.md)，依此类推。完整步骤见[架构和功能开发流程设计](架构和功能开发流程设计.md)的「加一个新功能的完整流程」。

## 两条约定

1. **文档和代码不一致时，以代码为准，然后改文档。** 代码是唯一运行的真相，不一致就当 bug 修。
2. **改表必须同时改 `tables.dart` 和[数据库设计](数据库设计.md)。** 错的字段名会让人写出跑不通的代码，所以这条单独强调，`tables.dart` 文件头也写了同样的提醒。
